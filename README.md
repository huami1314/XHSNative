# XHSNative

小红书 iOS 液态玻璃插件。液态玻璃需要 iOS 26 及以上，频道、保存、点点和双击放大在更低的系统上也能用。

> **测试环境**：小红书 `9.55` · iOS `27.0`

## 功能

- **底部标签栏**：支持拖动排序、隐藏和滚动收起，搜索入口独立显示，可与发布对调，可显示文字。
- **首页顶栏**：液态边缘效果，及部分布局调整，频道可隐藏、排序、改名，可隐藏红线。
- **液态玻璃**：覆盖图文笔记、视频、搜索、评论、消息和个人页，支持分项开关，部分控件可调不透明度。
- **保存**：笔记和评论里的图片、实况、视频无水印保存，可解除作者的保存限制。
- **其他**：禁用点点 AI，双击放大笔记图片。

设置入口在小红书「设置」→「XHSNative」。

## 编译

在装有 Theos 环境下的机器运行：

```bash
make
```

产物在 `packages/XHSNative-<版本号>.dylib`。
